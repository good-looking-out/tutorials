# How to Use Chorus-Ensemble in Ableton Live

Chorus-Ensemble layers or modulates delayed copies of an audio signal to create thickening, stereo motion, flanging, and vibrato. It is included with every Live 12 edition. Start with an audible audio or instrument track, then refer to Ableton’s current [Chorus-Ensemble reference](https://www.ableton.com/en/manual/live-audio-effect-reference/#chorus-ensemble) as you adjust the device.

The source video demonstrates the Live 11 version of the device. Since then, Live 12.4 renamed its **Classic** mode **Chorus** and added the **Delay Time** and **Tap Count** controls. This guide uses current Live 12.4 names and behavior.

## Add the device and choose a mode

In Live’s Browser, open **Audio Effects** and drag **Chorus-Ensemble** to the selected track’s device chain. Its display contains buttons for three modes:

- **Chorus** adds two time-modulated delayed signals to the input. Use it for conventional chorus, subtle thickening, and light movement.
- **Ensemble** uses three delayed signals with offset modulation phases for a fuller, smoother result.
- **Vibrato** modulates pitch rather than layering the signal with delays, producing a more obvious pitch variation.

Choose the mode before refining the rest of the device. Chorus and Ensemble share several controls, while Vibrato exposes controls intended for pitch movement instead of a wet/dry chorus blend.

## Build a Chorus sound with Delay Time and Tap Count

Select **Chorus** for the current version of the mode labeled Classic in the source video. Use **Amount** to set how far the delay times move and **Rate** to set the speed of that movement. Lower settings generally keep the original attack and pitch clearer; higher settings make the modulation easier to hear.

Use the **Delay Time** chooser to determine how the two chorus delays behave. **Auto** scales each tap’s delay time with the modulation amount, retaining the dynamic behavior of older sets and presets. Select a fixed delay time when a stable effect is more useful, such as when processing bass or guitar and avoiding additional phasing or pitch movement matters.

Use **Tap Count** to switch between the one- and two-tap structures. A single tap can create a simpler, broader chorus similar to a hardware pedal. Compare it with two taps at the same Amount and Rate before deciding which structure better supports the source.

## Create width and movement with Ensemble

Select **Ensemble** when a denser three-delay chorus is appropriate. Set **Rate** first, then raise **Amount** until the movement is present without obscuring the source. Because Ensemble distributes modulation phases across three signals, modest changes can produce a noticeably richer result than they do in Chorus mode.

In Chorus and Ensemble modes, use **Width** to control the stereo balance of the wet signal. At 0%, the effect is mono; at 100%, its mid and side balance is equal; and at 200%, the sides are louder than the middle. Start around the center position and check the mix in mono before relying on an especially wide setting.

Enable the high-pass filter when low-frequency components should receive less modulation. Raise its frequency only as far as necessary, then compare the bypassed device with the processed signal to make sure the low end retains the intended weight.

## Set up a dedicated Vibrato effect

Choose **Vibrato** for direct pitch movement without the delayed layering used by Chorus and Ensemble. Adjust **Rate** for the speed of the movement and **Amount** for its depth. A low Rate and Amount can add slight instability, while higher settings make the pitch change deliberately apparent.

Use **Offset** to set the phase relationship of the left and right modulation waveforms. At 180 degrees, they are fully out of phase. **Shape** continuously changes the waveform from a sine at 0% to a triangle at 100%, allowing smoother or more angular pitch movement.

**Feedback** and **Dry/Wet** are unavailable in Vibrato mode. Set the device’s position in the chain and its **Output** level with that fully processed behavior in mind, particularly if it is being used on a return track or automated within a mix.

## Refine tone, feedback, and the mix balance

In Chorus and Ensemble modes, increase **Feedback** cautiously to feed more of each channel’s output back into its input. Higher values intensify the effect, add upper harmonic content, and can create audible delays after playback stops. Enable **Feedback Invert** with high feedback for a hollower character.

Use **Warmth** to add subtle distortion and filtering when a less clean sound suits the material. Set **Output** so that comparisons are not biased by an unintended level increase, then use **Dry/Wet** to balance the processed and original signal. For a return track, set Dry/Wet to 100% and use the source track’s send level to control the amount of effect.

Chorus-Ensemble is most useful when its modulation supports a defined role in the arrangement: light thickening for a lead, controlled width for a pad, a dense Ensemble texture for guitar, or a clearly audible Vibrato transition. Revisit Rate, Amount, and the mix balance in the full arrangement rather than judging them only on a soloed track.
