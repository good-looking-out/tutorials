# How to Use Help View and File Manager in Ableton Live

Live includes learning and file-management tools inside the application. The source video shows the earlier **Help View**. In current Live 12.4 releases, **Learn View** replaces the earlier Help View and its built-in lessons, while File Manager remains the tool for resolving and managing project files. This guide identifies the current workflow for [Ableton Live](https://www.ableton.com/en/live/).

## Use Learn View in current Live 12

Open **Learn View** from Live’s View menu when you want in-application guidance. It provides structured learning modules with written explanations and video material, and you can filter modules by topic or mark them complete. The video can be viewed in Learn View or opened in a Picture-in-Picture window so that you can follow it while working in the main interface.

If you use a release before Live 12.4, the equivalent area is called **Help View**, as shown in the source video. Earlier Help View lessons, Pack information, navigation controls, and manual links should not be confused with the newer Learn View layout.

## Find targeted reference information

Use the relevant tool for the question at hand:

- Open **Info View** and hover a control for a brief explanation and, when available, its shortcut.
- Use **Learn View** for guided feature instruction in current Live 12.
- Open the current Live manual from the Help menu for complete reference information.
- Use Pack information pages when a Pack supplies its own usage notes or description.

Version matters for names and layouts. If a video describes a control that cannot be found, compare the installed Live version with the manual’s version selector before assuming that the feature was removed.

## Open File Manager

Use **File > Manage Files** to open File Manager. It analyzes the current Project or User Library and helps you find material that Live needs or material that may no longer be needed.

File Manager is especially useful when a Set opens with missing samples, after moving a Project, or before preparing an archive. Start from the available management category that matches the task, such as the current Project or User Library, instead of moving files in Finder or Explorer while Live is trying to resolve them.

## Resolve missing media deliberately

When a Project cannot find samples, use File Manager to review the missing files and search locations. Connect the original drive first if the project depended on external storage. If the files were moved, point Live to the folder that contains the originals and confirm the matches before saving.

Avoid accepting a different file merely because it has a similar name. A mismatched sample can make a Set play incorrectly even though the missing-file warning disappears. Once the correct material is restored, save the Set and use **Collect All and Save** when the Project must become portable.

## Manage content without breaking references

Use File Manager to understand a Project’s dependencies before removing unused content or copying a project. It can also provide an overview of the User Library, including missing or external files. Leave original source files intact until the project opens and plays correctly from its intended location.

For future work, keep each project in its own folder, use stable Browser locations for personal libraries, and collect dependent files before transferring a Set to another computer. These habits reduce the need for recovery later.
