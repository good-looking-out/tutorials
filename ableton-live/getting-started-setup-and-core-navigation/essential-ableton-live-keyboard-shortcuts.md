# Essential Ableton Live Keyboard Shortcuts

Keyboard shortcuts reduce repeated navigation in [Ableton Live](https://www.ableton.com/en/live/), but some shortcuts shown in older videos changed in Live 12. This guide uses current Live 12 commands and separates macOS from Windows where they differ.

## Start with navigation and playback

Use these commands frequently enough to learn them first:

| Task | Windows | macOS |
| --- | --- | --- |
| Start or stop playback | `Space` | `Space` |
| Continue playback from the stopped position | `Shift`+`Space` | `Shift`+`Space` |
| Switch Session and Arrangement views | `Tab` | `Tab` |
| Switch Device and Clip View | `Shift`+`Tab` or `F12` | `Shift`+`Tab` or `F12` |
| Open Settings | `Ctrl`+`,` | `Cmd`+`,` |
| Show or hide the Browser | `Ctrl`+`Alt`+`5` | `Cmd`+`Option`+`5` |
| Search the Browser | `Ctrl`+`F` | `Cmd`+`F` |

The source video reflects an earlier version of Live, where the Browser shortcut used `B`. In current Live 12, use the `5` shortcut shown above. Check the menu command if a shortcut does not work, since keyboard focus, a text-entry field, or the Computer MIDI Keyboard can change what a key does.

## Create, save, and export efficiently

| Task | Windows | macOS |
| --- | --- | --- |
| New Live Set | `Ctrl`+`N` | `Cmd`+`N` |
| Save Live Set | `Ctrl`+`S` | `Cmd`+`S` |
| Save Live Set As | `Ctrl`+`Shift`+`S` | `Cmd`+`Shift`+`S` |
| Export Audio/Video | `Ctrl`+`Shift`+`R` | `Cmd`+`Shift`+`R` |
| Add Audio Track | `Ctrl`+`T` | `Cmd`+`T` |
| Add MIDI Track | `Ctrl`+`Shift`+`T` | `Cmd`+`Shift`+`T` |
| Add Return Track | `Ctrl`+`Alt`+`T` | `Cmd`+`Option`+`T` |
| Undo | `Ctrl`+`Z` | `Cmd`+`Z` |

Save after a meaningful edit rather than relying on memory. Use **Save Live Set As** for a revision that belongs in the same project, and use **Save a Copy** or **Collect All and Save** when creating a portable version.

## Edit tracks and devices

Select the item that should receive the command before using an editing shortcut:

- Rename a selected track, clip, scene, or other renameable item with `Ctrl`+`R` on Windows or `Cmd`+`R` on macOS.
- Group selected tracks or devices with `Ctrl`+`G` or `Cmd`+`G`.
- Reset a parameter with `Delete`, or double-click it.
- Load the selected Browser device with `Enter`.
- Fold or unfold the selected track with `U` when the Computer MIDI Keyboard is off.

Use `M` to toggle the Computer MIDI Keyboard. When it is on, its note keys take priority over several single-key commands, so turn it off before using commands such as `U` or `S` for editing and soloing.

## Practice shortcuts in a small Set

Add a few tracks and clips, then practice switching views, searching the Browser, renaming a track, grouping tracks, saving, and undoing. This creates reliable habits without risking an active project.

Live’s shortcut set expands well beyond these essentials. Use Ableton’s current [Live Keyboard Shortcuts](https://www.ableton.com/en/manual/live-keyboard-shortcuts/) reference as the authority when a version differs.
