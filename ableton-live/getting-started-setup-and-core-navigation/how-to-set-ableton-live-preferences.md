# How to Set Ableton Live Preferences

Ableton Live’s global configuration window controls the application’s appearance, audio and MIDI connections, content locations, recording behavior, plug-ins, and update settings. In current Live 12 releases this window is named **Settings**; it was called **Preferences** in earlier releases and in the accompanying video. Open [Ableton Live](https://www.ableton.com/en/live/) before making changes, and keep an audio device connected if you plan to configure sound or MIDI hardware.

## Open Settings

Open Settings with `Cmd`+`,` on macOS or `Ctrl`+`,` on Windows. You can also use Live’s application menu. The window remembers the most recently used page, so confirm the page name before changing a setting.

The pages cover separate parts of Live’s behavior:

- **Display & Input** controls the theme, color behavior, display scale, and input-related options.
- **Audio** selects audio devices and settings such as sample rate, buffer size, and available channels.
- **Link, Tempo & MIDI** configures synchronization, control surfaces, and MIDI ports.
- **File & Folder**, **Library**, and **Plug-Ins** manage locations, browser behavior, and plug-in scanning.
- **Record, Warp & Launch** controls defaults for recording, warping, and clip launching.
- **Licenses & Updates** contains authorization, update, and usage-data options.

Settings are global rather than part of one Live Set. Change only the options that serve a specific workflow, and make a note of any hardware-related setting before changing it.

## Adjust the display and input options

Use **Display & Input** when Live’s presentation or interaction needs adjusting. Select a theme that is comfortable for long sessions, then use the display-scale setting if text or controls are too small or too large for the screen.

Live also provides color and customization options for tracks, clips, the grid, and the interface. These affect presentation rather than the audio in a Set. Try changes with an open Set, then return to the factory-style appearance if a custom combination makes controls harder to distinguish.

## Configure audio and MIDI on their own pages

The **Audio** page is the right place to select an audio interface, configure its input and output channels, and balance latency against computer load. Device, driver, sample-rate, and buffer-size changes can affect playback, so test them with a simple Set before recording an important performance.

Use **Link, Tempo & MIDI** for controllers and synchronization. A MIDI keyboard that plays instruments usually needs its input port enabled for Track, while a controller used for custom parameter mapping needs Remote. Enable Sync only when the device must exchange timing information with Live.

For a detailed hardware workflow, see Ableton’s current guides for [setting up an audio interface](https://help.ableton.com/hc/en-us/articles/211476789-Setting-up-an-Audio-Interface) and [Live’s MIDI Settings](https://help.ableton.com/hc/en-us/articles/209774205-Live-s-MIDI-Settings).

## Manage files, content, and plug-ins carefully

Use **File & Folder** for file-handling options and **Library** for the User Library, Packs, and Browser behavior. Keep frequently used custom content in clearly named folders rather than adding a whole drive or a large general-purpose folder to the Browser. This keeps content easier to find and avoids unnecessary indexing.

Use **Plug-Ins** to enable the plug-in formats and folders that are actually needed. If a newly installed plug-in does not appear, first confirm that it is compatible with the installed version of Live and the operating system, then rescan only the relevant plug-in location.

## Set recording and launch behavior before a session

The **Record, Warp & Launch** page includes defaults that affect newly created material. Review the default recording file type and bit depth before starting an audio-recording project. Review warp and launch settings before importing a large collection of loops or preparing clips for performance.

Avoid changing recording or warp defaults halfway through a project unless the reason is clear. Existing clips retain their own settings, so a global change mainly affects material created or imported afterward.

## Use Settings as a controlled checklist

Settings are most useful when you revisit them for a defined purpose: connect a new device, change a library location, prepare a recording session, or troubleshoot performance. Leave working audio and MIDI configuration in place once it has been tested, then return to it only when the hardware or workflow changes.

For the current page-by-page reference, consult Ableton’s [First Steps manual section](https://www.ableton.com/en/live-manual/12/first-steps/). The source walkthrough is Ableton’s [Learn Live: Setting your Preferences](https://www.youtube.com/watch?v=TwQC9EU2BYE) video.
