# How to Save an Ableton Live Set and Project

Saving in [Ableton Live](https://www.ableton.com/en/live/) involves both the Live Set and the Project folder that holds it. A saved Set records its clips, arrangement, devices, and control settings, but an audio clip can still depend on a sample stored elsewhere. Use the appropriate save command for ordinary progress, alternate versions, copies, and portable projects.

## Understand the Set and Project relationship

A **Live Set** is the `.als` document containing the arrangement, clips, device settings, and other musical decisions. A **Project** is the folder that contains one or more related Sets and their project-managed files. On the first save, Live creates or uses a Project folder at the location you choose.

Save related versions of one song in the same Project. Start a separate Project for unrelated work so that files, backups, and later transfers stay organized.

## Save ordinary progress

Choose **File > Save Live Set** or press `Cmd`+`S` on macOS or `Ctrl`+`S` on Windows. The first save asks for a name and location; later saves update that Set. You can save during playback, though saving a large project may take a moment.

Use meaningful, stable names from the start, such as `song-title-v01`. Save at natural milestones before extensive recording, sound design, or arrangement changes.

## Create an alternate Set or a copy

Choose **File > Save Live Set As** for a new named version in the same Project, such as an arrangement revision or mix alternative. Use it when the new version remains related to the original project.

Choose **File > Save a Copy** when you need a duplicate in another location. A copy is useful for a handoff, backup, or experimental branch, but it does not automatically make every referenced sample portable. Check its Project folder before deleting, moving, or sending the original material.

## Collect dependent files for a portable Project

Choose **File > Collect All and Save** when the Project needs to carry the samples and other dependent media that the Set references. Review the collection categories in the dialog and select only the sources needed for the intended copy, which can include media from elsewhere, other Projects, the User Library, or Factory Packs.

Live copies the selected dependencies into the Project and saves the Set. This is useful before moving a project to another computer, archiving it, or sharing it with a collaborator. It increases the Project size, so use it intentionally rather than as a replacement for everyday saving.

## Verify a saved Project

After saving or collecting, close and reopen the Set from its intended Project folder. Confirm that clips load, no missing-media warning appears, and the Set plays as expected. For a transfer, test the copied Project from the destination storage before removing the original.

Regularly saving the Set protects the current work; collecting files protects its dependencies. Ableton’s [Managing Files and Sets manual chapter](https://www.ableton.com/en/live-manual/12/managing-files-and-sets/) explains Project folders and collection in detail. The accompanying source is [Learn Live: Saving Projects](https://www.youtube.com/watch?v=M6lIz4Fyc2w).
