# How to Use Your Own Sounds and Samples in Ableton Live

You can use personal samples and sound libraries in [Ableton Live](https://www.ableton.com/en/live/) without moving them into the application’s factory content. Add well-organized folders to the Browser, load files where they are needed, and save reusable work to the User Library.

## Organize the source folders first

Keep samples in a stable, clearly named folder structure before adding them to Live. A folder can remain on an internal drive, external drive, or another location that stays available when you open a Set. Avoid reorganizing or renaming it after using its files in projects, because Live may need help locating moved material.

Add only discrete content folders. Adding an entire hard drive, a large cloud-synchronization folder, Desktop, or Downloads can make Browser indexing unnecessarily slow and makes the source material harder to browse.

## Add a personal folder to Places

1. Open Live’s Browser and find **Places** in the sidebar.
2. Click **Add Folder**, or drag a folder from Finder on macOS or Explorer on Windows into Places.
3. Select the folder containing the samples or presets.
4. Wait for Live to finish indexing it, then open the new label in Places.

Adding a folder does not copy or move it. It creates a Browser reference, so changes made in Finder or Explorer remain changes to the original folder. If an external drive is disconnected or the folder is moved, the label can appear unavailable; use its context menu to locate the folder again or remove the reference.

## Load samples in the right context

Use the Browser to drag audio to the part of Live that suits the result:

- Drag an audio file to a Session View clip slot or Arrangement View to create an audio clip.
- Drag a one-shot or loop to a MIDI track’s device area to load it into a suitable sampling workflow when prompted or supported.
- Drag a sound onto a Drum Rack pad to place it on that pad.
- Drag an instrument, Rack, or effect preset to a selected track or device chain.

Preview a file before loading it. After loading, confirm the clip’s warp and gain settings, especially when the sample must follow the project tempo or when it was recorded at a different level than the Set.

## Save reusable presets to User Library

The **User Library** is Live’s location for content you create, including device presets, Racks, default presets, clips, grooves, templates, and custom samples. To preserve a completed Drum Rack or device setup, use its save control, give the preset a useful name, and save it in an appropriate User Library folder.

When a preset or clip relies on samples, Live’s handling of those dependent files is controlled by its Library Browser Behavior settings. Check the resulting preset from the User Library before deleting or relocating any source samples.

## Keep projects portable when necessary

A Browser folder reference is ideal for a personal library that remains available on one system. A project that must travel to another computer needs its dependent media collected into the Project instead. Use **Collect All and Save** when preparing a copy for collaboration, backup, or transfer, and select only the source categories that need to be copied.

Use Places for ongoing access, the User Library for reusable creations, and a Project folder for the material required by one Set. Ableton’s [Browser manual chapter](https://www.ableton.com/en/live-manual/12/working-with-the-browser/) explains custom folders and the User Library. The associated source is [Learn Live: Using your sounds and samples](https://www.youtube.com/watch?v=0t9M15n2iAA).
