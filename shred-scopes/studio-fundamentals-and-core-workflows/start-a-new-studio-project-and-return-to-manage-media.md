# How to Start a New Studio Project and Return to Manage Media

Studio keeps the active source, templates, preview state, and Source Composite arrangement in one editing workspace. Starting another project requires returning that workspace to its startup state after any work that should be retained has been saved.

The separate "Manage Media" area provides access to saved telemetry, templates, images, and export records without serving as the active video editor.

## Start a project from the Studio startup screen

1. Open [Shred Scopes](https://shredscopes.com/) on a desktop computer.
2. Sign in and select "Studio" from the site navigation.
3. Choose a source:
   - "Choose Clip" for one original local GoPro file
   - "Use Sample Clip" for an included sample
   - "Choose Metadata from Account" for saved telemetry
4. Wait for the source to become ready.
5. Select a built-in or custom template.

The Template Editor opens when the telemetry and template are ready.

Selecting two or more local GoPro clips can start Batch Mode rather than the standard single-source workflow.

## Save work before starting another project

Before resetting or leaving Studio, inspect every open template tab for an unsaved indicator.

Use:

- "Save" for changes to an existing custom template
- "Save As New" for a built-in template, a new design, or a separate version
- "Save As Template" in Source Composite when the current overlay stack should be retained as a reusable custom template

A Source Composite template stack does not include the source video. The original GoPro file remains a separate local file.

Wait for the save state to clear before closing a tab or resetting the workspace.

## Reset Studio to start another project

Select "Reset" in the top toolbar when the current source and open template workspaces should be cleared.

Studio checks for unresolved work before proceeding. Save the required changes or confirm that they can be discarded. After the reset completes, the startup source picker returns.

The top toolbar's "Reset" is different from these similarly named controls:

- "New" starts a blank template. It does not choose a new telemetry source or clear the current project.
- The Source Composite panel's reset restores source and overlay framing. It does not return Studio to startup.
- "CHANGE TEMPLATE" replaces the design in the active tab. It does not clear the source.
- "Choose New Clip" changes the source within the current workflow and can affect template compatibility.

Use the top toolbar's reset when the goal is a fully separate project.

## Return to Manage Media

Open the account navigation and select "Manage Media." Resolve any save or discard prompt before leaving the editor.

The Manage Media page provides links to the account-backed Studio libraries:

- "Open Studio" returns to the editor.
- "Import GoPro Clips" extracts and saves telemetry from one or more local source files.
- "Telemetry Library" lists saved telemetry extractions.
- "Favorite Templates" lists favorited built-in and custom templates.
- "Custom Templates" lists account-saved template designs.
- "Manage Image Assets" lists images available to custom templates.
- "Export Log" lists completed and attempted video exports.

These pages manage retained account items. They do not contain the original GoPro source footage, which remains on the local device.

## Start from saved telemetry in Manage Media

To begin from a saved extraction:

1. Open "Telemetry Library" from Manage Media.
2. Find the required telemetry item.
3. Use its Studio action to load it into the editor.
4. Choose a template if one is not already open.

Saved telemetry can drive template preview and standalone overlay export. Select "Select Source Video" and choose the matching original GoPro clip before using Source Composite.

## Start from a saved custom template

To begin from an account template:

1. Open "Custom Templates" or "Favorite Templates."
2. Find the required design.
3. Open it in Studio.
4. Load a local clip, saved telemetry, or a sample if the workspace has no active data.

The template and telemetry are separate parts of the project. Opening a template does not automatically supply the GoPro data it needs.

## Return from Manage Media to Studio

Select "Open Studio" on the Manage Media page. Studio opens at the appropriate source or editor state available for the session.

If a clean project is required and an earlier workspace remains active, use the top toolbar's "Reset," resolve any unsaved work, and choose the next source from the startup picker.

## Safe project-change checklist

Before moving from one project to another, confirm that:

- Required custom template changes have been saved.
- Any reusable Source Composite stack has been saved as a template.
- A completed export exists at the intended destination.
- The original GoPro file remains available if later compositing is required.
- Resetting the workspace will not discard changes that must be retained.

Following this sequence keeps account libraries, local source footage, open editing state, and completed output clearly separated.
